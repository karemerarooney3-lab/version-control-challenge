# Git and GitHub Notes

## What is Version Control?
Version control tracks file changes over time.

## What is Git?
Git is software used to manage project versions locally.

## What is GitHub?
GitHub stores Git repositories online.

## Basic Commands

Clone:
```bash
git clone URL
```

Check status:

```bash
git status
```

Commit:

```bash
git commit -m "message"
```
these are notes
## Collaboration
GitHub allows multiple developers to work together.

## Benefits
- Tracks changes
- Prevents losing work
- Supports teamwork
